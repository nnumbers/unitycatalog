# Storage Location Security Implementation - Complete Overview

## Executive Summary

This document describes the complete implementation of storage location security and credential vending for non-admin table creation in Unity Catalog. The implementation enables multi-tenant security by enforcing storage boundaries at the catalog and schema levels, allowing non-admin users to create tables with CREATE_TABLE privilege instead of requiring METASTORE OWNER.

**Project Status:** Milestones 1-5 Complete ✅

## Problem Statement

### Before This Implementation

1. **No Storage Boundaries**: Users could request credentials for any S3 path, creating security risks in multi-tenant environments
2. **Admin-Only Table Creation via Spark**: The `/temporary-path-credentials` endpoint required METASTORE OWNER privilege, blocking non-admin users from creating tables via Spark connector
3. **Missing Hierarchy**: Catalogs and schemas didn't have storage configuration, preventing automatic path generation for managed tables
4. **Inconsistent Authorization**: REST API allowed CREATE_TABLE privilege for table creation, but Spark connector required OWNER privilege for the same operation

### After This Implementation

1. ✅ **Secure Storage Boundaries**: Schema-level storage locations enforce multi-tenant security
2. ✅ **Non-Admin Table Creation**: Users with CREATE_TABLE privilege can obtain credentials for table creation
3. ✅ **Storage Hierarchy**: Catalog → Schema → Table storage location hierarchy fully implemented
4. ✅ **Path Validation**: Comprehensive validation prevents unauthorized storage access
5. ✅ **Consistent Authorization**: Same privileges (CREATE_TABLE) work for both REST API and Spark connector

## Architecture Overview

### Storage Location Hierarchy

```
Catalog
├── storage_root: s3://my-catalog-bucket/
│   └── Required for managed tables
│   └── Defines the root bucket for the catalog
│
└── Schema
    ├── storage_location: s3://my-catalog-bucket/my-schema/
    │   └── Required for managed tables in this schema
    │   └── Acts as security boundary for external tables
    │   └── Must be under catalog's storage_root
    │
    └── Tables
        ├── Managed Table
        │   └── storage_location: s3://my-catalog-bucket/my-schema/table1/
        │   └── Auto-generated by server
        │
        └── External Table
            └── storage_location: s3://my-catalog-bucket/my-schema/custom/table2/
            └── User-provided, validated against schema boundary
```

### Key Security Principles

1. **Schema as Security Boundary**: Each schema's `storage_location` defines the maximum scope of storage access
2. **Path Validation**: All requested storage locations must fall within the schema boundary
3. **Auto-Generated Managed Paths**: Server controls managed table paths to prevent path manipulation
4. **Privilege-Based Authorization**: CREATE_TABLE + USE_SCHEMA + USE_CATALOG (no OWNER required)

#### Changes Made

**1. TableRepository Validation Logic**
- **File:** [server/src/main/java/io/unitycatalog/server/persist/TableRepository.java](server/src/main/java/io/unitycatalog/server/persist/TableRepository.java)
- Added validation in `createTable()` method

**Validation Flow:**

```java
public TableInfo createTable(CreateTable createTable) {
  // ... existing validation ...

  return TransactionManager.executeWithTransaction(
      sessionFactory,
      session -> {
        String catalogName = tableInfo.getCatalogName();
        String schemaName = tableInfo.getSchemaName();
        String schemaFullName = catalogName + "." + schemaName;

        // Get schema storage location
        SchemaInfo schema = schemaRepository.getSchema(schemaFullName);
        String schemaStorageLocation = schema.getStorageLocation();

        // Validate for EXTERNAL tables
        if (TableType.EXTERNAL.equals(tableInfo.getTableType())) {
          String requestedLocation = tableInfo.getStorageLocation();

          if (requestedLocation == null || requestedLocation.isEmpty()) {
            throw new BaseException(
                ErrorCode.INVALID_ARGUMENT,
                "External tables must specify a storage_location");
          }

          if (schemaStorageLocation == null || schemaStorageLocation.isEmpty()) {
            throw new BaseException(
                ErrorCode.INVALID_ARGUMENT,
                "Cannot create external table: Schema " + schemaFullName +
                " does not have storage_location configured");
          }

          // Security check: location must be within schema boundary
          if (!StorageLocationValidator.isWithinBoundary(
              requestedLocation, schemaStorageLocation)) {
            throw new BaseException(
                ErrorCode.PERMISSION_DENIED,
                "Table storage location must be within schema boundary. " +
                "Requested: " + requestedLocation +
                ", Schema boundary: " + schemaStorageLocation);
          }
        }

        // Proceed with table creation...
      });
}
```

**Security Guarantees:**
1. ✅ External tables MUST provide storage_location
2. ✅ External tables can ONLY be created in schemas with storage_location configured
3. ✅ External table location MUST be within schema boundary
4. ✅ Managed tables still blocked (awaiting future implementation)

**Error Messages:**

| Scenario | Error Code | Message |
|----------|-----------|---------|
| External table without location | INVALID_ARGUMENT | External tables must specify a storage_location |
| Schema without storage_location | INVALID_ARGUMENT | Cannot create external table: Schema {name} does not have storage_location configured |

```java
@Post("")
public HttpResponse generateTemporaryTableCredential(
    GenerateTemporaryTableCredential generateTemporaryTableCredential) {

  // Extract parameters
  String catalogName = generateTemporaryTableCredential.getCatalogName();
  String schemaName = generateTemporaryTableCredential.getSchemaName();
  String tableName = generateTemporaryTableCredential.getTableName();
  String requestedLocation = generateTemporaryTableCredential.getUrl();

  // Authorization: CREATE_TABLE + USE_SCHEMA + USE_CATALOG (NOT OWNER!)
  authorizeForTableCreation(catalogName, schemaName);

  // Get schema storage location
  String schemaFullName = catalogName + "." + schemaName;
  SchemaInfo schema = schemaRepository.getSchema(schemaFullName);
  String schemaStorageLocation = schema.getStorageLocation();

  // Determine final storage location
  String storageLocation;
  if (requestedLocation != null && !requestedLocation.isEmpty()) {
    // External table: validate within boundary
    if (!StorageLocationValidator.isWithinBoundary(
        requestedLocation, schemaStorageLocation)) {
      throw new BaseException(ErrorCode.PERMISSION_DENIED,
          "Requested storage location must be within schema boundary");
    }
    storageLocation = requestedLocation;
  } else {
    // Managed table: auto-generate path
    storageLocation = StorageLocationValidator.generateManagedTablePath(
        schemaStorageLocation, tableName);
  }

  // Vend credentials with READ + WRITE privileges
  Set<CredentialContext.Privilege> privileges = Set.of(SELECT, UPDATE);
  TemporaryCredentials credentials =
      cloudCredentialVendor.vendCredential(storageLocation, privileges);

  // Return validated URL with credentials
  credentials.setUrl(storageLocation);
  return HttpResponse.ofJson(credentials);
}
```

**Authorization Logic:**

```java
private void authorizeForTableCreation(String catalogName, String schemaName) {
  String authorizeExpression =
      """
      #authorize(#principal, #schema, CREATE_TABLE) &&
      #authorize(#principal, #schema, USE_SCHEMA) &&
      #authorize(#principal, #catalog, USE_CATALOG)
      """;

  // KeyMapper builds full schema name from catalog + schema
  Map<SecurableType, Object> resourceKeys =
      keyMapper.mapResourceKeys(
          Map.of(
              METASTORE, "metastore",
              CATALOG, catalogName,
              SCHEMA, schemaName));

  if (!evaluator.evaluate(userRepository.findPrincipalId(),
      authorizeExpression, resourceKeys)) {
    throw new BaseException(ErrorCode.PERMISSION_DENIED,
        "Access denied for table creation.");
  }
}
```

## Security Model

### Multi-Tenant Protection

**1. Schema Storage Boundaries**
- Each schema defines a `storage_location` that acts as a security perimeter
- All storage access must fall within this boundary
- Prevents cross-tenant data access

**2. Path Validation**
- `StorageLocationValidator.isWithinBoundary()` performs comprehensive checks:
  - ✅ Same URI scheme (s3://)
  - ✅ Same bucket/host
  - ✅ Path is under boundary path
  - ✅ Handles trailing slash normalization
  - ❌ Rejects different buckets
  - ❌ Rejects path traversal attempts

**3. Auto-Generated Managed Paths**
- Server controls managed table path generation
- Users cannot manipulate paths via API
- Format: `{schema_storage_location}/{table_name}/`
- Prevents directory traversal attacks

**4. Privilege-Based Authorization**
- **Required Privileges:**
  - `CREATE_TABLE` on schema
  - `USE_SCHEMA` on schema
  - `USE_CATALOG` on catalog
- **NOT Required:**
  - `METASTORE OWNER` (old requirement)
  - This enables non-admin users to create tables

### Authorization Flow

```
User Request
    ↓
1. Extract catalog_name, schema_name, table_name
    ↓
2. Check Privileges:
   - CREATE_TABLE on schema?
   - USE_SCHEMA on schema?
   - USE_CATALOG on catalog?
    ↓
3. Get schema.storage_location
    ↓
4. Validate/Generate Storage Location:
   - External table? → Validate within boundary
   - Managed table? → Auto-generate path
    ↓
5. Vend Temporary Credentials (1-hour TTL)
    ↓
6. Return {url, aws_temp_credentials, expiration_time}
```

### Threat Protection

| Attack Vector | Protection Mechanism |
|--------------|---------------------|
| Access arbitrary S3 bucket | ❌ Rejected: Different bucket check |
| Path traversal (../../) | ❌ Rejected: Path prefix validation |
| Cross-tenant access | ❌ Rejected: Schema boundary enforcement |
| Privilege escalation | ❌ Rejected: Authorization checks |
| Managed path manipulation | ❌ Prevented: Server-side generation |
